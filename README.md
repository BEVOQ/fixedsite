# Algarve Luxury Site — Starter Kit

This is a lightweight starter for a luxury animated Next.js website (Algarve landscaping / renovations / microcement).

## Quickstart
1) Install Node.js 20+.
2) In this folder:
   - `npm install`
   - `npm run dev`

## Replace demo assets
Demo image paths are in `/public/demo/*` and referenced in `content/site.ts`.
Replace them with real images (prefer AVIF/WebP), keeping file names or updating paths.

## Key components
- `components/LightsOnImage.tsx` — tap hotspots to reveal the lit layer
- `components/FocusShiftSection.tsx` — scroll-based focus shift (starter)

## Specs
See `/docs/*` for brand, IA, components, and motion rules.
