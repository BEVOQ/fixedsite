# Motion System (starter)

## Tokens
- --dur-fast: 200ms
- --dur-med: 450ms
- --dur-slow: 800ms
- --ease-lux: cubic-bezier(.2,.8,.2,1)

## Rules
1) No bouncy easing.
2) Keep reveals subtle.
3) Prefer opacity/transform over layout-changing animations.
4) Disable expensive effects on mobile.
5) Respect prefers-reduced-motion.
