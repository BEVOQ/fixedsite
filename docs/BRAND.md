# Brand System (starter)

## Tone
Modern Mediterranean luxury: calm, architectural, restrained. Avoid hype and gimmicks.

## Palette (CSS variables in app/globals.css)
- bg (chalk): rgb(var(--c-bg))
- surface (travertine): rgb(var(--c-surface))
- ink: rgb(var(--c-ink))
- muted: rgb(var(--c-muted))
- accent (midnight teal): rgb(var(--c-accent))
- olive: rgb(var(--c-olive))
- brass: rgb(var(--c-brass))

## Typography (recommended)
- Display: editorial serif for H1/H2
- Body/UI: modern sans for paragraphs, buttons, nav
(Choose actual font files later.)

## Motion rules (summary)
- Slow, premium easing
- 3 reveal patterns max
- Disable heavy parallax on mobile
- Always respect prefers-reduced-motion
